# 25. Check if Object Instance of Class

## 📝 題目（English）

Write a function that checks if a given value is an instance of a given class or superclass.

An object is considered an instance of a class if it has access to that class's methods.

There are no constraints on the data types that can be passed to the function. For example, the value or the class could be undefined.

## 📝 題目（中文）

請實作一個函式，判斷某個值是否為指定 class（或其父類別）的實例。

定義：若該物件可以存取該 class 的方法，則視為該 class 的 instance。

---

## 💡 解題思路

* 本題核心為 **Prototype Chain（原型鏈）遍歷**。
* 使用 `Object.getPrototypeOf(obj)` 取得當前原型。
* 逐層往上查找（while loop）：

  * 若某一層 prototype === classFunction.prototype → 回傳 true
* 若走到 null → 回傳 false

---

## 💻 程式碼

```js
/**
 * @param {any} obj
 * @param {any} classFunction
 * @return {boolean}
 */
var checkIfInstanceOf = function(obj, classFunction) {
    if(obj === null || obj === undefined || typeof classFunction !== 'function') return false;
    
    let type = Object.getPrototypeOf(obj);        
    while(type !== null) {
        if(type === classFunction.prototype) {
            return true;
        }
        type = Object.getPrototypeOf(type);        
    }
    
    return false;
};

/**
 * checkIfInstanceOf(new Date(), Date); // true
 */
```

---

## 📌 重點整理

* 使用 `Object.getPrototypeOf` 遍歷原型鏈
* 比對 `classFunction.prototype`
* 本質為手寫 `instanceof`
* 時間複雜度 O(depth of prototype chain)

---

## ⚠️ 注意事項（重要）

* `null` / `undefined` 沒有 prototype → 直接 false
* `classFunction` 必須為 function
* primitive（如 number / string）不會通過（除非包裝成物件）

---

## 🔥 延伸觀念

* 等價於：`obj instanceof classFunction`
* Prototype Chain：

  * obj → **proto** → prototype → ... → null
* 與 Day 23（prototype）直接相關
* 是 JavaScript 核心機制之一

---

## 🧠 Prototype Chain 圖解（概念）

```text
obj
 ↓
obj.__proto__
 ↓
Class.prototype
 ↓
Object.prototype
 ↓
null
```
