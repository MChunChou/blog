# 29. Generate Fibonacci Sequence

## 📝 題目（English）

Write a generator function that returns a generator object which yields the Fibonacci sequence.

The Fibonacci sequence is defined by:

Xn = Xn-1 + Xn-2

The first few numbers are:
0, 1, 1, 2, 3, 5, 8, 13

---

## 📝 題目（中文）

請實作一個 generator function，產生 Fibonacci 數列。

Fibonacci 定義：

* Xn = Xn-1 + Xn-2
* 起始為 0, 1

---

## 💡 解題思路

* 使用 **Generator（生成器）+ yield**
* 維護兩個變數：

  * x1：當前值
  * x2：下一個值
* 每次 yield 當前值，然後更新狀態

---

## 💻 程式碼

```js
/**
 * @return {Generator<number>}
 */
var fibGenerator = function*() {
    let x1 = 0
    let x2 = 1     
    while(true) {        
        yield x1;
        [x1 , x2]  = [x2, x1 + x2]        
    }
};

/**
 * const gen = fibGenerator();
 * gen.next().value; // 0
 * gen.next().value; // 1
 */
```

---

## 📌 重點整理

* `function*` 宣告 generator
* `yield` 逐步回傳值
* `while(true)` 建立無限序列
* 解構賦值更新狀態（[x1, x2]）

---

## ⚠️ 注意事項

* 無限 generator 需搭配控制（例如只取前 n 個）
* 每次 `next()` 才會執行到下一個 yield

---

## 🔥 延伸觀念

* lazy evaluation（惰性計算）
* iterator protocol
* 與 async generator（for await）延伸

---

## 🚀 實務應用

* 大資料流處理（streaming）
* 分批讀取（lazy loading）
* 無限資料序列（例如 ID generator）

---

## 🧠 執行流程圖

```text
yield 0 → yield 1 → yield 1 → yield 2 → ...
   ↓        ↓        ↓
 state 更新（x1, x2）
```
