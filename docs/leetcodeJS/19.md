# 19. Array of Objects to Matrix

## 📝 題目（English）

Write a function that converts an array of objects `arr` into a matrix `m`.

* `arr` is an array of objects or arrays. Each item can be deeply nested.
* Values may include numbers, strings, booleans, and null.

Rules:

* The first row `m[0]` should be the column names.
* Without nesting: column names are unique keys.
* With nesting: column names are paths joined by `.`.
* Each remaining row corresponds to an item in `arr`.
* Missing values should be filled with `""`.
* Columns must be sorted lexicographically.

## 📝 題目（中文）

將一個物件陣列 `arr` 轉換為矩陣 `m`。

* `arr` 中元素可能是物件或陣列，且可能深層巢狀
* 值可能包含 number / string / boolean / null

規則：

* 第一列為欄位名稱
* 若有巢狀，欄位名稱為 path（用 `.` 串接）
* 每一列對應一個物件
* 缺少的值填入空字串 `""`
* 欄位需依字典序排序

---

## 💡 解題思路

* 核心：**Flatten（展平）+ 路徑紀錄 + 結構轉換**
* 使用遞迴將每個 object 展平成 `{ path: value }`
* 使用 `Set` 收集所有出現過的 key（欄位）
* 將所有 key 排序後作為 header
* 每一筆資料依序填入對應值（缺少補 `""`）

---

## 💻 程式碼

```js
/**
 * @param {Array} arr
 * @return {Matrix}
 */
var jsonToMatrix = function(arr) {
    const keySet = new Set();
    const value = []
    let index = 0
    const get = (val, prefix) => {
        let key = prefix
        
        if(typeof val === 'object' && val != null) {            
            if(Array.isArray(val)) {
                val.forEach((v, i) => {
                    get(v, key? key + '.' + i : i+'');
                })              
            } else {
                for(let k in val) {
                    get(val[k], key? key + '.' + k : k)
                }   
                
            }                    
        } else {
            keySet.add(key);
         
            value[index][key] = val
        }        
    }    

    arr.forEach((a, i) => {
        index = i
        value[index] = {}
        get(a, '');
    })

    const matrix = []

    if(value) {
        const keys = Array.from(keySet).sort();        
        matrix.push(keys)
        value.forEach((v) => {
            let row = []            
            keys.forEach(k => {                  
                if(v[k] !== undefined) {
                    row.push(v[k])
                } else {
                    row.push('')
                }
            })

            matrix.push(row)
        })

    }

    return matrix
};
```

---

## 📌 重點整理

* 使用遞迴 flatten 巢狀結構
* key path 使用 `.` 串接（含 array index）
* `Set` 收集所有欄位
* 排序後建立 matrix header
* 缺值補空字串

## 🔥 延伸觀念（進階）
