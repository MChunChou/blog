# 15. Debounce

## 📝 題目（English）

Given a function `fn` and a time in milliseconds `t`, return a debounced version of that function.

A debounced function is a function whose execution is delayed by `t` milliseconds and whose execution is cancelled if it is called again within that window of time. The debounced function should also receive the passed parameters.

For example, let `t = 50ms`, and the function was called at `30ms`, `60ms`, and `100ms`. The first 2 function calls would be cancelled, and the 3rd function call would be executed at `150ms`. If instead `t = 35ms`, the 1st call would be cancelled, the 2nd would be executed at `95ms`, and the 3rd would be executed at `135ms`.

## 📝 題目（中文）

給定一個函式 `fn` 與一個時間 `t`（毫秒），請回傳一個 debounce（防抖）版本的函式。

Debounce 的行為如下：

* 呼叫後會延遲 `t` 毫秒才執行
* 若在這段時間內再次呼叫，則會取消前一次的執行
* 最終只會執行「最後一次呼叫」
* 需保留傳入參數

---

## 💡 解題思路

* 本題核心為 **Timer 控制 + 取消機制（Cancellation）**。
* 使用一個變數 `timeout` 記錄目前的計時器。
* 每次呼叫時：

  * 若已有計時器，先 `clearTimeout` 取消
  * 建立新的 `setTimeout`
* 時間到後才執行 `fn`。

---

## 💻 程式碼

```js
/**
 * @param {Function} fn
 * @param {number} t milliseconds
 * @return {Function}
 */
var debounce = function(fn, t) {
    let timeout = null;

    return function(...args) {
        if(timeout) {
            clearTimeout(timeout)
        }
        
        timeout = setTimeout(()=> {
            fn(...args)
            clearTimeout(timeout)
        }, t)
    }
};

/**
 * const log = debounce(console.log, 100);
 * log('Hello'); // cancelled
 * log('Hello'); // cancelled
 * log('Hello'); // Logged at t=100ms
 */
```

---

## 📌 重點整理

* 使用 `setTimeout` 延遲執行
* 使用 `clearTimeout` 取消前一次任務
* 只保留最後一次呼叫（Trailing execution）
* 常見應用：搜尋輸入、resize、scroll 事件優化
