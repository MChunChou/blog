# 1. Create Hello World Function

## 📝 題目（English）

Write a function `createHelloWorld`.
It should return a new function that always returns "Hello World".

## 📝 題目（中文）

請實作一個函式 `createHelloWorld`，
它會回傳一個新的函式，而該函式無論接收什麼參數，都會回傳字串 `"Hello World"`。

---

## 💡 解題思路

* 此題主要考察 **Closure（閉包）** 概念。
* 外層函式回傳一個內層函式。
* 內層函式不論接收任何參數，皆固定回傳 `"Hello World"`。

---

## 💻 程式碼

```js
/**
 * @return {Function}
 */
var createHelloWorld = function() {
    return function(...args) {
        return 'Hello World'
    }
};
```

---

## 📌 重點整理

* 使用 Closure 回傳函式
* 忽略輸入參數（使用 `...args`）
* 固定回傳結果
