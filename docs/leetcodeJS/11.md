# 11. Sleep

## 📝 題目（English）

Given a positive integer `millis`, write an asynchronous function that sleeps for `millis` milliseconds. It can resolve any value.

## 📝 題目（中文）

給定一個正整數 `millis`，請實作一個非同步函式，使其等待 `millis` 毫秒後再完成（resolve）。

---

## 💡 解題思路

* 本題核心為 **Promise + 非同步（Asynchronous）控制**。
* 使用 `setTimeout` 延遲執行 `resolve`。
* 將 `setTimeout` 包裝在 `Promise` 中。
* `async` 函式回傳 Promise，因此可以搭配 `await` 使用。

---

## 💻 程式碼

```js
/**
 * @param {number} millis
 */
async function sleep(millis) {
    return new Promise((resolve, reject)=>{    
        setTimeout(()=> resolve(), millis);
    })
}

/**
 * let t = Date.now()
 * sleep(100).then(() => console.log(Date.now() - t)) // 100
 */
```

---

## 📌 重點整理

* 使用 Promise 包裝 `setTimeout`
* `resolve()` 代表非同步任務完成
* 可搭配 `await sleep(ms)` 控制流程
* 常見應用：延遲執行、重試機制、API 節流（throttle）
