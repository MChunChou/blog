# 4. Apply Transform Over Each Element in Array

## 📝 題目（English）

Given an integer array `arr` and a mapping function `fn`, return a new array with a transformation applied to each element.

The returned array should be created such that `returnedArray[i] = fn(arr[i], i)`.

Please solve it **without** the built-in `Array.map` method.

## 📝 題目（中文）

給定一個整數陣列 `arr` 與一個映射函式 `fn`，請回傳一個新陣列，其中每個元素都經過轉換。

回傳的陣列需滿足：`returnedArray[i] = fn(arr[i], i)`。

請在**不使用內建 `Array.map` 方法**的情況下完成此題。

---

## 💡 解題思路

* 本題核心為手動實作 `map` 行為。
* 使用 `for` 迴圈遍歷陣列。
* 每次將 `fn(arr[i], i)` 的結果放入新陣列。
* 回傳最終建立的新陣列。

---

## 💻 程式碼

```js
/**
 * @param {number[]} arr
 * @param {Function} fn
 * @return {number[]}
 */
var map = function(arr, fn) {
    const newArr = []
    for(let i = 0; i < arr.length; i++) {
      newArr.push(fn(arr[i], i))
    }

  return newArr
};
```

---

## 📌 重點整理

* 手動實作 `Array.map` 的核心概念
* `fn` 會接收 `(element, index)` 兩個參數
* 回傳新陣列（不可直接修改原陣列）
* 屬於基礎的 Array Transformation 題型
