# 14. Cache With Time Limit

## 📝 題目（English）

Write a class that allows getting and setting key-value pairs, however a time until expiration is associated with each key.

The class has three public methods:

* `set(key, value, duration)`: accepts an integer key, an integer value, and a duration in milliseconds. Once the duration has elapsed, the key should be inaccessible. The method should return `true` if the same un-expired key already exists and `false` otherwise. Both the value and duration should be overwritten if the key already exists.
* `get(key)`: if an un-expired key exists, it should return the associated value. Otherwise it should return `-1`.
* `count()`: returns the count of un-expired keys.

## 📝 題目（中文）

請實作一個類別，用來儲存 key-value 資料，並且每個 key 都有過期時間（expiration）。

此類別需提供三個方法：

* `set(key, value, duration)`：設定 key 與 value，並指定過期時間（毫秒）。若該 key 在未過期情況下已存在，回傳 `true`，否則回傳 `false`。若 key 已存在，需覆蓋 value 與過期時間。
* `get(key)`：若 key 存在且尚未過期，回傳對應 value，否則回傳 `-1`。
* `count()`：回傳目前尚未過期的 key 數量。

---

## 💡 解題思路

* 本題核心為 **Cache + 過期機制（Expiration） + setTimeout**。
* 使用 `Map` 儲存 key 與其對應的資料（value + timeout）。
* 每次 `set`：

  * 若 key 已存在，先 `clearTimeout` 清除舊的計時器。
  * 建立新的 `setTimeout`，時間到時刪除該 key。
* `get`：直接檢查是否存在於 Map 中。
* `count`：回傳 Map 的 size。

---

## 💻 程式碼

```js
var TimeLimitedCache = function() {
    this.db = new Map();      
};

/**
 * @param {number} key
 * @param {number} value
 * @param {number} time until expiration in ms
 * @return {boolean} if un-expired key already existed
 */
TimeLimitedCache.prototype.set = function(key, value, duration) {
    const isUnExpired = this.db.has(key)    
    
    if(this.db.has(key)) {
        const timeout = this.db.get(key).time;        
        clearTimeout(timeout)
    }

    const time = setTimeout(()=>{
        this.db.delete(key)
    }, duration)

    this.db.set(key, {
        value: value,
        time: time
    })

    return isUnExpired    
};

/**
 * @param {number} key
 * @return {number} value associated with key
 */
TimeLimitedCache.prototype.get = function(key) {
    return this.db.has(key)? this.db.get(key).value : -1
};

/**
 * @return {number} count of non-expired keys
 */
TimeLimitedCache.prototype.count = function() {
    return this.db.size
};

/**
 * Your TimeLimitedCache object will be instantiated and called as such:
 * var obj = new TimeLimitedCache()
 * obj.set(1, 42, 1000); // false
 * obj.get(1) // 42
 * obj.count() // 1
 */
```

## 📌 重點整理

* 使用 `Map` 作為快取結構
* 搭配 `setTimeout` 實現自動過期（TTL, Time-To-Live）
* 更新 key 時需 `clearTimeout` 避免重複計時
* `count()` 直接回傳目前有效 key 數量
* 常見應用：快取系統（cache）、session 管理、API 資料暫存
