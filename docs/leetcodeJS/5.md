# 5. Filter Elements from Array

## 📝 題目（English）

Given an integer array `arr` and a filtering function `fn`, return a filtered array `filteredArr`.

The `fn` function takes one or two arguments:

* `arr[i]` - number from the arr
* `i` - index of `arr[i]`

`filteredArr` should only contain the elements from the `arr` for which the expression `fn(arr[i], i)` evaluates to a **truthy** value. A truthy value is a value where `Boolean(value)` returns `true`.

Please solve it **without** the built-in `Array.filter` method.

## 📝 題目（中文）

給定一個整數陣列 `arr` 與一個過濾函式 `fn`，請回傳一個過濾後的陣列 `filteredArr`。

`fn` 函式可接收以下參數：

* `arr[i]`：陣列中的元素
* `i`：該元素的索引

`filteredArr` 只應包含那些讓 `fn(arr[i], i)` 回傳 **truthy（真值）** 的元素。

請在**不使用內建 `Array.filter` 方法**的情況下完成此題。

---

## 💡 解題思路

* 本題為手動實作 `filter` 行為。
* 使用 `for` 迴圈遍歷陣列。
* 當 `fn(arr[i], i)` 回傳 truthy 時，將該元素加入新陣列。
* 最後回傳過濾後的新陣列。

---

## 💻 程式碼

```js
/**
 * @param {number[]} arr
 * @param {Function} fn
 * @return {number[]}
 */
var filter = function(arr, fn) {
    const newArr = []
    for(let i = 0; i<arr.length ; i++) {
      if(fn(arr[i], i)){
        newArr.push(arr[i])
      }     
    }

     return newArr
};
```

---

## 📌 重點整理

* 手動實作 `Array.filter` 核心邏輯
* 判斷條件為 truthy（非單純 boolean）
* `fn` 可接收 `(element, index)`
* 回傳新陣列（不改變原陣列）
* 常見於資料篩選（條件過濾）場景
