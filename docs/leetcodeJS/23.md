# 23. Array Prototype Last

## 📝 題目（English）

Write code that enhances all arrays such that you can call the array.last() method on any array and it will return the last element. If there are no elements in the array, it should return -1.

You may assume the array is the output of `JSON.parse`.

## 📝 題目（中文）

請擴展所有陣列，使其可以呼叫 `array.last()` 方法並回傳最後一個元素。

* 若陣列為空，回傳 `-1`

---

## 💡 解題思路

* 本題核心為 **Prototype 擴展 + this 綁定**。
* 在 `Array.prototype` 上新增方法 `last`。
* 使用 `this` 指向當前呼叫的陣列。
* 透過 `this.length - 1` 取得最後一個元素。
* 使用 `??` 處理空陣列情況。

---

## 💻 程式碼

```js
Array.prototype.last = function() {
    return this[this.length - 1] ?? -1
};

/**
 * const arr = [1, 2, 3];
 * arr.last(); // 3
 */
```

---

## 📌 重點整理

* `this` 指向呼叫該方法的陣列
* `this.length - 1` 取得最後一個元素
* `??`（Nullish Coalescing）用於處理 `undefined`
* 空陣列時回傳 `-1`

---

## ⚠️ 注意事項（重要）

* 擴展 `Array.prototype` 在實務中需謹慎，可能造成全域污染（global pollution）
* 可能與其他 library 衝突
* 在 production 通常會避免直接修改 prototype

---

## 🔥 延伸觀念

* Prototype 是 JavaScript 核心機制（Prototype Chain）
* 類似方法：

  * `Array.prototype.first`
  * `Array.prototype.sum`
* 可用於 polyfill 設計
* 與 class / OOP 設計有關
