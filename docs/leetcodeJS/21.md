# 21. Chunk Array

## 📝 題目（English）

Given an array `arr` and a chunk size `size`, return a chunked array.

A chunked array contains the original elements in `arr`, but consists of subarrays each of length `size`. The length of the last subarray may be less than `size` if `arr.length` is not evenly divisible by `size`.

You may assume the array is the output of `JSON.parse`. In other words, it is valid JSON.

Please solve it without using lodash's `_.chunk` function.

## 📝 題目（中文）

給定一個陣列 `arr` 與一個大小 `size`，請將陣列分割為多個子陣列。

* 每個子陣列長度為 `size`
* 最後一個子陣列長度可以小於 `size`

---

## 💡 解題思路

* 本題核心為 **分段（Chunking）+ 迭代（Iteration）**。
* 使用 while 迴圈，每次切出長度為 `size` 的子陣列。
* 利用 `slice(i, i + size)` 取得區段。
* 每次 index 增加 `size`。

---

## 💻 程式碼

```js
/**
 * @param {Array} arr
 * @param {number} size
 * @return {Array[]}
 */
var chunk = function(arr, size) {
    if(size <= 0) return [];
    
    const result = []    
    const len = arr.length;

    let i = 0
    while(i < len) {
        result.push(arr.slice(i, i+size))
        i += size
    }

    return  result
};
```

---

## 📌 重點整理

* 使用 `slice` 做區間切割
* 每次位移 `size`
* 時間複雜度 O(n)
* 空間複雜度 O(n)

---

## 🔥 延伸觀念

* 常見於：分頁（pagination）、批次處理（batch processing）
* 可應用於 API 請求分批（搭配 promisePool）
* 與 windowing / sliding window 不同（這題是固定分段）
