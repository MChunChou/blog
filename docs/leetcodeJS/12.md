# 12. Promise Time Limit

## 📝 題目（English）

Given an asynchronous function `fn` and a time `t` in milliseconds, return a new time limited version of the input function. `fn` takes arguments provided to the time limited function.

The time limited function should follow these rules:

* If the `fn` completes within the time limit of `t` milliseconds, the time limited function should resolve with the result.
* If the execution of the `fn` exceeds the time limit, the time limited function should reject with the string `"Time Limit Exceeded"`.

## 📝 題目（中文）

給定一個非同步函式 `fn` 與一個時間限制 `t`（毫秒），請回傳一個具有時間限制的函式。

此函式需符合以下規則：

* 若 `fn` 在 `t` 毫秒內完成，則回傳其結果（resolve）
* 若執行時間超過 `t` 毫秒，則回傳錯誤（reject），內容為 `"Time Limit Exceeded"`

---

## 💡 解題思路

* 本題核心為 **Promise 控制 + Timeout 機制**。
* 建立兩個 Promise：

  * `success`：原始函式 `fn(...args)`
  * `failed`：`setTimeout` 觸發 reject
* 使用 `Promise.race`，誰先完成就回傳誰的結果。

---

## 💻 程式碼

```js
/**
 * @param {Function} fn
 * @param {number} t
 * @return {Function}
 */
var timeLimit = function(fn, t) {
	return async function(...args) {
       const failed = new Promise((resolve, reject) => {
           setTimeout(()=>{
               reject("Time Limit Exceeded");
           }, t);
       })
       const success = Promise.resolve(fn(...args))
       return Promise.race([success, failed])
    }
};

/**
 * const limited = timeLimit((t) => new Promise(res => setTimeout(res, t)), 100);
 * limited(150).catch(console.log) // "Time Limit Exceeded" at t=100ms
 */
```

---

## 📌 重點整理

* 使用 `Promise.race` 控制多個非同步競爭
* `setTimeout` 可用於建立 timeout 機制
* 成功與失敗分別對應 resolve / reject
* 常見應用：API timeout、請求保護、非同步流程控制
