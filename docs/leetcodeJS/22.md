# 22. Flatten Deeply Nested Array

## 📝 題目（English）

Given a multi-dimensional array `arr` and a depth `n`, return a flattened version of that array.

A multi-dimensional array is a recursive data structure that contains integers or other multi-dimensional arrays.

A flattened array is a version of that array with some or all of the sub-arrays removed and replaced with the actual elements in that sub-array. This flattening operation should only be done if the current depth of nesting is less than `n`. The depth of the elements in the first array are considered to be `0`.

Please solve it without the built-in `Array.flat` method.

## 📝 題目（中文）

給定一個多維陣列 `arr` 與一個深度 `n`，請回傳展平後的陣列。

* 多維陣列可以包含整數或其他陣列
* 展平只會在巢狀深度小於 `n` 時發生
* 第一層深度為 `0`
* 不可使用內建 `Array.flat`

---

## 💡 解題思路

* 核心：**遞迴（Recursion）+ 深度控制（Depth Control）**
* 當 `n === 0` 時直接回傳原陣列（不再展開）
* 逐一遍歷元素：

  * 若為陣列 → 遞迴展開，並將深度減 1
  * 若為一般值 → 直接加入結果
* 使用展開運算子 `...` 將子結果攤平

---

## 💻 程式碼

```js
/**
 * @param {any[]} arr
 * @param {number} depth
 * @return {any[]}
 */
var flat = function (arr, n) {
    if(n == 0 ) return arr;
    
    let res = []

    arr.forEach((a) => {
        if(Array.isArray(a)) {
            res.push(...flat(a, n-1));
        } else {
            res.push(a)   
        }        
    })
        
    return res
};
```

---

## 📌 重點整理

* 使用遞迴展平巢狀結構
* `n` 控制最大展平深度
* `Array.isArray` 判斷是否需要繼續展開
* 展開運算子 `...` 用於合併子結果

---

## 🔥 延伸觀念

* `flat(Infinity)` 可完全展平（本題可模擬）
* 與 Day 19（flatten object）概念一致，但資料型態不同
* 可改寫為迭代（stack）版本以避免深遞迴
* 大資料時需注意 recursion depth（可能 stack overflow）

---

## ⚠️ Edge Cases

* `n = 0` → 原樣回傳
* 空陣列 → 回傳 `[]`
* 混合型別（number / string / null）需正常保留
