# 7. Function Composition

## 📝 題目（English）

Given an array of functions `[f1, f2, f3, ..., fn]`, return a new function `fn` that is the function composition of the array of functions.

The function composition of `[f(x), g(x), h(x)]` is:

```
fn(x) = f(g(h(x)))
```

The function composition of an empty list of functions is the identity function `f(x) = x`.

You may assume each function in the array accepts one integer as input and returns one integer as output.

## 📝 題目（中文）

給定一個函式陣列 `[f1, f2, f3, ..., fn]`，請回傳一個新函式 `fn`，此函式為這些函式的組合（function composition）。

例如 `[f(x), g(x), h(x)]` 的組合為：

```
fn(x) = f(g(h(x)))
```

若函式陣列為空，則回傳一個恆等函式（identity function），即 `f(x) = x`。

可以假設陣列中的每個函式皆接收一個整數並回傳一個整數。

---

## 💡 解題思路

* 本題核心為 **Function Composition（函式組合）**。
* 執行順序為「由右至左」，也就是最後一個函式先執行。
* 使用迴圈從陣列尾端開始，逐步將結果傳入前一個函式。
* 若函式陣列為空，直接回傳輸入值（identity）。

---

## 💻 程式碼

```js
/**
 * @param {Function[]} functions
 * @return {Function}
 */
var compose = function(functions) {
	return function(x) {
        const len = functions.length
        for(let i = len - 1; i >= 0 ; i--) {
            x = functions[i](x)
        }

        return x
    }
};

/**
 * const fn = compose([x => x + 1, x => 2 * x])
 * fn(4) // 9
 */
```

---

## 📌 重點整理

* 函式組合為「由右到左」執行
* 空陣列對應 identity function（`x => x`）
* 每個函式的輸出會成為下一個函式的輸入
* Functional Programming 常見核心概念
