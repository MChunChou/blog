# 27. Event Emitter

## 📝 題目（English）

Design an `EventEmitter` class that supports subscribing to events and emitting them.

### Methods

* `subscribe(eventName, callback)`

  * Register a callback for an event.
  * Multiple listeners per event are allowed.
  * Callbacks are executed in subscription order.
  * Returns an object with `unsubscribe()` to remove the callback.

* `emit(eventName, args?)`

  * Triggers all callbacks for the event.
  * Returns an array of callback results in order.
  * If no listeners, return `[]`.

---

## 📝 題目（中文）

設計一個 `EventEmitter` 類別，支援事件訂閱與觸發。

### 方法

* `subscribe(event, cb)`：註冊事件
* `emit(event, args)`：觸發事件
* `unsubscribe()`：取消訂閱

---

## 💡 解題思路

* 使用 **Hash Map（物件）** 儲存事件

  * `eventName → callback[]`
* `subscribe`：將 callback push 到陣列
* `emit`：遍歷 callback 並執行
* `unsubscribe`：從陣列中移除 callback

---

## 💻 程式碼

```js
class EventEmitter {
  events = {};

  subscribe(event, cb) {
    let key = 0;
    if (this.events[event]) {
      key = this.events[event].length;
      this.events[event][key] = cb;
    } else {
      this.events[event] = [cb];
    }

    return {
      unsubscribe: () => {
        if (this.events[event]) {
          this.events[event].splice(key, 1);
        }
      }
    };
  }

  emit(event, args = []) {
    if (this.events[event]) {
      return this.events[event].map((cb) => cb(...args));
    }
    return [];
  }
}
```

---

## 📌 重點整理

* event → callback[] 映射
* 支援多 listener
* callback 執行順序需一致
* emit 回傳結果陣列

---

## ⚠️ 注意事項（重要）

* 使用 `splice` 會影響 index（unsubscribe 順序問題）
* 若多次 unsubscribe 或交錯操作可能出現 bug

---

## 🔥 改良版本（更穩定）

```js
class EventEmitter {
  events = {};

  subscribe(event, cb) {
    if (!this.events[event]) this.events[event] = new Set();
    this.events[event].add(cb);

    return {
      unsubscribe: () => {
        this.events[event]?.delete(cb);
      }
    };
  }

  emit(event, args = []) {
    if (!this.events[event]) return [];
    return Array.from(this.events[event]).map((cb) => cb(...args));
  }
}
```
