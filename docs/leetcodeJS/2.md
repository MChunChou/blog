# 2. Counter

## 📝 題目（English）

Given an integer `n`, return a counter function.
This counter function initially returns `n` and then returns `1` more than the previous value every subsequent time it is called (`n`, `n + 1`, `n + 2`, etc).

## 📝 題目（中文）

給定一個整數 `n`，請回傳一個計數器函式。
此函式在第一次呼叫時回傳 `n`，之後每次呼叫都會回傳比前一次多 `1` 的數值（例如：`n`、`n + 1`、`n + 2`...）。

---

## 💡 解題思路

* 本題核心為 **Closure（閉包）**。
* 外層函式 `createCounter` 接收初始值 `n`。
* 回傳的內層函式會「記住」這個 `n`。
* 每次呼叫時透過 `n++` 回傳當前值，並自動遞增。

---

## 💻 程式碼

```js
/**
 * @param {number} n
 * @return {Function} counter
 */
var createCounter = function(n) {
    return function() {        
        return n++    
    };
};

/**
 * const counter = createCounter(10)
 * counter() // 10
 * counter() // 11
 * counter() // 12
 */
```

---

## 📌 重點整理

* 利用 Closure 保存狀態（`n`）
* `n++` 先回傳再遞增（Post-increment）
* 每次呼叫共享同一個記憶體中的 `n`
