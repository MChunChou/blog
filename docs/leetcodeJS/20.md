# 20. Differences Between Two Objects

## 📝 題目（English）

Write a function that accepts two deeply nested objects or arrays `obj1` and `obj2` and returns a new object representing their differences.

Rules:

* Only include keys where values differ
* Each difference should be `[obj1 value, obj2 value]`
* Ignore keys that exist in only one object
* Arrays use index as keys
* Result should preserve nested structure

---

## 📝 題目（中文）

請實作一個函式，比較兩個深層物件或陣列 `obj1`、`obj2` 的差異。

規則：

* 只回傳「值不同」的 key
* 每個差異格式為 `[obj1值, obj2值]`
* 只存在於其中一方的 key 不處理
* 陣列以 index 當作 key
* 結果需保持巢狀結構

---

## 💡 解題思路

* 使用 **遞迴（Recursion）** 處理巢狀結構
* 遍歷 `obj1` 的 key
* 若兩邊 key 都存在：

  * 若為 object → 遞迴比較
  * 若為 primitive → 直接比較
* 若不同 → 記錄 `[obj1, obj2]`

---

## 💻 程式碼

```js
function objDiff(obj1, obj2) {
  const diffObj = {};
  Object.keys(obj1).forEach((key) => {
    const diff = {};
    if (Object.hasOwn(obj1, key) && Object.hasOwn(obj2, key)) {
      if (
        obj1[key] !== null &&
        obj2[key] !== null &&
        typeof obj1[key] === "object" &&
        typeof obj2[key] === "object"
      ) {
        const objDeepDiff = objDiff(obj1[key], obj2[key]);
        if (objDeepDiff && Object.keys(objDeepDiff).length > 0) {
          diffObj[key] = objDeepDiff;
        }
      } else {
        if (obj1[key] !== obj2[key]) {
          diffObj[key] = [obj1[key], obj2[key]];
        }
      }
    }
  });

  if (Object.keys(diffObj).length > 0) {
    return diffObj;
  }

  return;
}
```

---

## 📌 重點整理

* 遞迴比較 nested object / array
* 只處理「雙方都存在的 key」
* 差異格式為 `[before, after]`
* 空結果回傳 `undefined`

---

## ⚠️ 注意事項

* `typeof null === 'object'`（需特別排除）
* 陣列本質也是 object（透過 index 比較）
* 僅比較 obj1 的 keys（題目限制）
