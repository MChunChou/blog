# 16. Throttle

## 📝 題目（English）

Given a function `fn` and a time in milliseconds `t`, return a throttled version of that function.

A throttled function is first called without delay and then, for a time interval of `t` milliseconds, can’t be executed but should store the latest function arguments provided to call `fn` with them after the end of the delay.

## 📝 題目（中文）

給定一個函式 `fn` 與一個時間 `t`（毫秒），請回傳一個 throttle（節流）版本的函式。

Throttle 的行為如下：

* 第一次呼叫會立即執行
* 接下來的 `t` 毫秒內不會執行
* 若期間有新的呼叫，會記住「最後一次參數」
* 時間到後，使用最後一次參數再執行一次

---

## 💡 解題思路

* 本題核心為 **時間控制 + 任務排程（Scheduling）**。
* 使用 `timeout` 控制是否在冷卻期間（cooldown）。
* 使用 `memoryArgs` 記錄期間內最後一次呼叫的參數。
* 若正在 cooldown：更新 `memoryArgs`。
* 若不在 cooldown：立即執行並啟動 timer。
* timer 結束後：

  * 若有 `memoryArgs` → 再執行一次並重新啟動 timer
  * 若沒有 → 結束 cooldown

---

## 💻 程式碼

```js
/**
 * @param {Function} fn
 * @param {number} t
 * @return {Function}
 */
var throttle = function(fn, t) {
    let timeout = null;
    let memoryArgs = null;
    
    const execute = () => {
        if(memoryArgs !== null) {
            fn(...memoryArgs)
            memoryArgs = null
            timeout = setTimeout(execute, t)                                              
        }
        else {
            timeout = null
        }
    }
        
    return function (...args) {
        if(timeout) {
            memoryArgs = args
        } else {
            fn(...args);
            timeout = setTimeout(execute, t)
        }
  }
};

/**
 * const throttled = throttle(console.log, 100);
 * throttled("log"); // logged immediately.
 * throttled("log"); // logged at t=100ms.
 */
```

---

## 📌 重點整理

* throttle = 限制執行頻率（固定時間內最多執行一次）
* 保留最後一次呼叫（Trailing execution）
* 使用 timer + 狀態管理（timeout / memoryArgs）
* 常見應用：scroll、resize、drag、動畫更新

---

## 🔥 debounce vs throttle（快速對比）

| 特性             | debounce | throttle        |
| ---------------- | -------- | --------------- |
| 執行時機         | 最後一次 | 固定頻率        |
| 是否延遲         | 是       | 第一個立即      |
| 是否保留最後一次 | 是       | 是              |
| 使用場景         | 搜尋輸入 | scroll / resize |
