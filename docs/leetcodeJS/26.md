# 26. Call Function with Custom Context

## 📝 題目（English）

Enhance all functions to have the `callPolyfill` method.

The method accepts:

* An object `obj` as the first parameter (this context)
* Any number of additional arguments

The function should execute with `obj` as `this`, and pass the additional arguments.

⚠️ Please solve this **without using the built-in `Function.call` method**.

---

## 📝 題目（中文）

請為所有函式新增 `callPolyfill` 方法。

* 第一個參數 `obj` 為 `this` 綁定對象
* 其餘參數為函式執行時的參數
* 函式需以 `obj` 作為 `this` 執行

⚠️ 不可使用內建 `Function.call`

---

## 💡 解題思路

* 本題核心為 **this 綁定 + Function 方法模擬**。
* 使用 `apply` 來指定 `this` 並傳遞參數。
* `this` 指向呼叫 `callPolyfill` 的函式本身。

---

## 💻 程式碼

```js
/**
 * @param {Object} context
 * @param {Array} args
 * @return {any}
 */
Function.prototype.callPolyfill = function(context, ...args) {
    return this.apply(context, args);
}

/**
 * function increment() { this.count++; return this.count; }
 * increment.callPolyfill({count: 1}); // 2
 */
```

---

## 📌 重點整理

* `this` 指向呼叫的函式
* 使用 `apply(context, args)` 指定 this
* 可變參數（rest parameter）傳遞參數

---

## ⚠️ 注意事項（重要）

* 本解法使用了 `apply`（題目僅限制不能用 `call`）
* 若需完全手寫（不使用 call / apply / bind）：

  * 可將函式暫時掛到 context 上執行

---

## 🔥 進階寫法（完全手刻 call）

```js
Function.prototype.callPolyfill = function(context, ...args) {
    context = context ?? globalThis
    const fnKey = Symbol()

    context[fnKey] = this
    const result = context[fnKey](...args)
    delete context[fnKey]

    return result
}
```

---

## 🔥 延伸觀念

* `call` / `apply` / `bind` 三者差異
* this 綁定規則（default / implicit / explicit / new）
* 與 Day 25（instanceof）同為 JS runtime 核心機制
* Polyfill 設計技巧
