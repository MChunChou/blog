# 8. Allow One Function Call

## 📝 題目（English）

Given a function `fn`, return a new function that is identical to the original function except that it ensures `fn` is called at most once.

The first time the returned function is called, it should return the same result as `fn`.
Every subsequent time it is called, it should return `undefined`.

## 📝 題目（中文）

給定一個函式 `fn`，請回傳一個新函式。

此新函式與原本的 `fn` 行為相同，但限制 **最多只能被呼叫一次**。

* 第一次呼叫時，回傳與 `fn` 相同的結果
* 之後每次呼叫，都回傳 `undefined`

---

## 💡 解題思路

* 本題核心為 **Closure（閉包） + 狀態控制（State Control）**。
* 使用一個布林變數 `flag` 記錄是否已經呼叫過。
* 第一次呼叫時執行 `fn` 並更新 `flag`。
* 之後直接回傳 `undefined`，不再執行 `fn`。

---

## 💻 程式碼

```js
/**
 * @param {Function} fn
 * @return {Function}
 */
var once = function(fn) {
    let flag = false;
    return function(...args){        
        if(flag === false) {
            flag = true
            return fn(...args);
        }
        return undefined
    }
};

/**
 * let fn = (a,b,c) => (a + b + c)
 * let onceFn = once(fn)
 *
 * onceFn(1,2,3); // 6
 * onceFn(2,3,6); // returns undefined without calling fn
 */
```

---

## 📌 重點整理

* 使用 Closure 保存呼叫狀態（`flag`）
* 僅允許第一次執行原函式
* 後續呼叫直接返回 `undefined`
* 常見於：初始化邏輯、防止重複請求、事件只觸發一次等場景
