# 24. Group By

## 📝 題目（English）

Write code that enhances all arrays such that you can call the array.groupBy(fn) method on any array and it will return a grouped version of the array.

A grouped array is an object where:

* Each key is the output of `fn(arr[i])`
* Each value is an array containing all items in the original array with that key

The provided callback `fn` will accept an item in the array and return a string key.

The order of each value list should follow the original array order. Any order of keys is acceptable.

Please solve it without lodash's `_.groupBy` function.

## 📝 題目（中文）

請擴展陣列，使其可以呼叫 `array.groupBy(fn)`，並回傳分組後的結果。

規則如下：

* key 為 `fn(arr[i])` 的回傳值
* value 為所有對應該 key 的元素陣列
* 每個 group 內的順序需保持原陣列順序
* key 的順序不限

---

## 💡 解題思路

* 本題核心為 **分類（Grouping）+ Hash Map（物件）應用**。
* 使用一個物件 `group` 作為結果容器
* 遍歷陣列：

  * 計算 key = fn(item)
  * 若 key 已存在 → push
  * 若不存在 → 初始化為新陣列

---

## 💻 程式碼

```js
/**
 * @param {Function} fn
 * @return {Object}
 */
Array.prototype.groupBy = function(fn) {
  const group = {}

  this.forEach((eachArr) => {
    const key = fn(eachArr)
    if(group[key]) {
      group[key].push(eachArr)
    } else {
      group[key] = [eachArr]
    }
  })

  return group
};

/**
 * [1,2,3].groupBy(String) // {"1":[1],"2":[2],"3":[3]}
 */
```

---

## 📌 重點整理

* 使用物件作為 hash map（key → array）
* 善用 callback fn 產生分組條件
* 保持原始順序（push）
* 時間複雜度 O(n)

---

## ⚠️ 注意事項（重要）

* 擴展 `Array.prototype` 可能造成全域污染
* key 會被轉為字串（object key 特性）
* 若 key 為複雜型別（object），需特別處理（例如 JSON.stringify）

---

## 🔥 延伸觀念

* 類似 SQL 的 `GROUP BY`
* 常見於資料統計、分類顯示（UI）
* 可搭配 `map` / `reduce` 做進一步轉換
* 可改寫為 `reduce` 版本（面試加分）

```js
const groupBy = (arr, fn) => {
  return arr.reduce((acc, item) => {
    const key = fn(item)
    acc[key] = acc[key] || []
    acc[key].push(item)
    return acc
  }, {})
}
```
