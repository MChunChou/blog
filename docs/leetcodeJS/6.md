# 6. Array Reduce Transformation

## 📝 題目（English）

Given an integer array `nums`, a reducer function `fn`, and an initial value `init`, return a reduced array.

A reduced array is created by applying the following operation:

```
val = fn(init, nums[0])
val = fn(val, nums[1])
val = fn(val, nums[2])
...
```

until every element in the array has been processed. The final value of `val` is returned.

If the length of the array is `0`, it should return `init`.

Please solve it **without** using the built-in `Array.reduce` method.

## 📝 題目（中文）

給定一個整數陣列 `nums`、一個 reducer 函式 `fn`，以及一個初始值 `init`，請回傳經過累積運算後的結果。

累積運算過程如下：

```
val = fn(init, nums[0])
val = fn(val, nums[1])
val = fn(val, nums[2])
...
```

直到陣列中所有元素都處理完畢，最後回傳 `val`。

若陣列長度為 `0`，則直接回傳 `init`。

請在**不使用內建 `Array.reduce` 方法**的情況下完成此題。

---

## 💡 解題思路

* 本題為手動實作 `reduce`（累積器）行為。
* 使用變數 `value` 作為累積結果（accumulator）。
* 初始值為 `init`。
* 每次迭代都將當前 `value` 與陣列元素傳入 `fn`，並更新 `value`。
* 最後回傳累積結果。

---

## 💻 程式碼

```js
/**
 * @param {number[]} nums
 * @param {Function} fn
 * @param {number} init
 * @return {number}
 */
var reduce = function(nums, fn, init) {
    let value = init
    if(nums.length == 0) return init;
    for (let i=0; i<nums.length; i++) {        
        value = fn(value, nums[i])    
    }

    return value
};
```

---

## 📌 重點整理

* 手動實作 `Array.reduce` 核心概念（累積器 accumulator）
* 初始值 `init` 決定最終結果的起點
* 每次迭代都會更新累積值
* 空陣列需直接回傳 `init`
* 常見應用：加總、乘積、物件累積、狀態聚合
