# 9. Memoize

## 📝 題目（English）

Given a function `fn`, return a memoized version of that function.

A memoized function is a function that will never be called twice with the same inputs. Instead, it will return a cached value.

You can assume there are 3 possible input functions: `sum`, `fib`, and `factorial`.

* `sum` accepts two integers `a` and `b` and returns `a + b`.
* `fib` accepts a single integer `n` and returns `1` if `n <= 1` or `fib(n - 1) + fib(n - 2)` otherwise.
* `factorial` accepts a single integer `n` and returns `1` if `n <= 1` or `factorial(n - 1) * n` otherwise.

## 📝 題目（中文）

給定一個函式 `fn`，請回傳該函式的 memoize（記憶化）版本。

Memoized 函式的特性是：

* 相同輸入參數只會計算一次
* 後續再次呼叫時，直接回傳快取（cache）結果

可假設輸入函式為以下三種之一：

* `sum(a, b)`：回傳 `a + b`
* `fib(n)`：若 `n <= 1` 回傳 `1`，否則回傳 `fib(n - 1) + fib(n - 2)`
* `factorial(n)`：若 `n <= 1` 回傳 `1`，否則回傳 `factorial(n - 1) * n`

---

## 💡 解題思路

* 本題核心為 **Closure + Cache（快取）機制**。
* 使用一個物件 `memFn` 作為快取表（key-value）。
* 將輸入參數轉換為字串（`JSON.stringify(args)`）作為 key。
* 若 key 已存在，直接回傳快取值。
* 若不存在，則執行函式並儲存結果。

---

## 💻 程式碼

```js
/**
 * @param {Function} fn
 */
function memoize(fn) {
    const memFn = {}
    return function(...args) {
        const key = JSON.stringify(args) ;
        if(memFn[key] == undefined || memFn[key] == null) {
            memFn[key] = fn(...args)    
        }
        
        return memFn[key]
    }
}


/** 
 * let callCount = 0;
 * const memoizedFn = memoize(function (a, b) {
 *   callCount += 1;
 *   return a + b;
 * })
 * memoizedFn(2, 3) // 5
 * memoizedFn(2, 3) // 5
 * console.log(callCount) // 1 
 */
```

---

## 📌 重點整理

* 使用 Closure 保存快取（cache）資料
* 相同輸入只計算一次（提升效能）
* key 通常需序列化（如 `JSON.stringify`）
* 常見應用：遞迴優化（fib）、計算結果快取、效能優化
* 屬於 Dynamic Programming（動態規劃）的基礎技巧
