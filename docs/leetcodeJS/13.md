# 13. Promise Pool

## 📝 題目（English）

Given an array of asynchronous functions `functions` and a concurrency limit `n`, return a promise that resolves after all the functions have completed.

Each function in `functions` returns a promise. At most `n` functions should be running in parallel at any given time.

## 📝 題目（中文）

給定一個非同步函式陣列 `functions` 與一個併發數限制 `n`，請回傳一個 Promise，當所有函式執行完成後 resolve。

* `functions` 中的每個函式都會回傳一個 Promise
* 同一時間最多只能有 `n` 個 Promise 在執行（併發控制）

---

## 💡 解題思路

* 本題核心為 **Concurrency Control（併發控制）**。
* 使用一個共享變數 `num` 來記錄目前執行到哪個任務。
* 建立 `n` 個 worker（透過 `Promise.all`），同時執行任務。
* 每個 worker 執行完一個任務後，遞迴呼叫自己繼續處理下一個任務。
* 直到所有任務完成。

---

## 💻 程式碼

```js
/**
 * @param {Function[]} functions
 * @param {number} n
 * @return {Function}
 */
var promisePool = async function(functions, n) {

    let num = 0;
    const execute = async function() {    
        if(num === functions.length) {
            return
        }

        await functions[num++]();
        await execute();
    }

    return Promise.all(Array(n).fill().map(execute))
};

/**
 * const sleep = (t) => new Promise(res => setTimeout(res, t));
 * promisePool([() => sleep(500), () => sleep(400)], 1)
 *   .then(console.log) // After 900ms
 */
```

---

## 📌 重點整理

* 控制同時執行的 Promise 數量（Concurrency Limit）
* 使用共享 index 分配任務
* 多個 worker 並行處理任務
* `Promise.all` 用於等待所有 worker 完成
* 常見應用：API 請求併發限制、批次處理、Queue 系統
