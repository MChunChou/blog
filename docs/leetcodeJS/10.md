# 10. Curry

## 📝 題目（English）

Given a function `fn`, return a curried version of that function.

A curried function is a function that accepts fewer or an equal number of parameters as the original function and returns either another curried function or the same value the original function would have returned.

In practical terms, if you called the original function like `sum(1,2,3)`, you would call the curried version like:

```
csum(1)(2)(3)
csum(1)(2,3)
csum(1,2)(3)
csum(1,2,3)
```

All these methods of calling the curried function should return the same value as the original.

## 📝 題目（中文）

給定一個函式 `fn`，請回傳該函式的柯里化（Currying）版本。

柯里化函式允許你分批傳入參數：

* 可以一次傳入部分參數
* 或多次傳入參數
* 最終參數數量滿足時才執行原函式

例如原本呼叫 `sum(1,2,3)`，柯里化後可寫成：

```
csum(1)(2)(3)
csum(1)(2,3)
csum(1,2)(3)
csum(1,2,3)
```

上述所有呼叫方式都應回傳相同結果。

---

## 💡 解題思路

* 本題核心為 **Closure + 參數累積（Argument Accumulation）**。
* 使用陣列 `args` 收集所有傳入的參數。
* 每次呼叫時將新參數加入 `args`。
* 當 `args.length === fn.length`（參數收集完成）時執行原函式。
* 否則回傳自身（遞迴呼叫）以繼續收集參數。

---

## 💻 程式碼

```js
/**
 * @param {Function} fn
 * @return {Function}
 */
var curry = function(fn) {
  return function curried(...arg) {

      if(args.length >= fn.length) {
        return fn(...args);
      }

      return (...nextArgs) => curried(...args, ...nextArgs);

  };
};

/**
 * function sum(a, b) { return a + b; }
 * const csum = curry(sum);
 * csum(1)(2) // 3
 */
```

---

## 📌 重點整理

* 使用 Closure 保存參數（`args`）
* 支援多種呼叫方式（partial application）
* `fn.length` 代表函式定義的參數數量
* 當參數收集完成才執行
* Functional Programming 核心技巧之一
