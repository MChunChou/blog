# 18. Convert Object to JSON String

## 📝 題目（English）

Given an object, return a valid JSON string of that object. You may assume the object only includes strings, integers, arrays, objects, booleans, and null.

The returned string should not include extra spaces. The order of keys should be the same as the order returned by `Object.keys()`.

Please solve it without using the built-in `JSON.stringify` method.

## 📝 題目（中文）

給定一個物件，請回傳該物件的 JSON 字串表示。

條件如下：

* 僅包含：string、number、array、object、boolean、null
* 回傳字串不得包含多餘空白
* key 順序需與 `Object.keys()` 一致
* 不可使用內建 `JSON.stringify`

---

## 💡 解題思路

* 本題核心為 **遞迴（Recursion） + 字串組裝（String Serialization）**。
* 針對不同型別進行處理：

  * string → 加上雙引號
  * number → 直接回傳
  * boolean → `true / false`
  * null → `"null"`
* 若為 Array：

  * 使用 `[]` 包裹
  * 每個元素遞迴處理
* 若為 Object：

  * 使用 `{}` 包裹
  * key 需加上雙引號
  * value 遞迴處理

---

## 💻 程式碼

```js
/**
 * @param {any} object
 * @return {string}
 */
var jsonStringify = function(object) {
    const result = []
    if(object === undefined) return 'undefined'
    if(typeof object === 'string') return '"'+object+'"'
    if(typeof object === 'number') return object
    if(object ===  null) return 'null';        
    if(typeof object === 'boolean') return object? 'true' : 'false'

    if(typeof object === 'object') {
        if(Array.isArray(object)) {
            result.push('[')
            object.forEach((o,i) => {
                result.push(jsonStringify(o))    
                if(object.length - 1 !== i ) {
                    result.push(',')
                }
            })        
            result.push(']')            
        } else {
            const keys = Object.keys(object)
            result.push('{')
            keys.forEach((key,i)=>{
                result.push(`"${key}":${jsonStringify(object[key])}`)
                if(keys.length-1 !== i ) {
                    result.push(',')
                }
            })
            result.push('}')            
        }   
    }

    return result.join('')
};
```

---

## 📌 重點整理

* 遞迴處理巢狀結構（array / object）
* 字串需加上雙引號
* 使用 `Object.keys()` 保持 key 順序
* 使用陣列累積字串並 `join` 提升效能
* 屬於序列化（serialization）問題

---

## 🔥 延伸觀念（進階）

* JSON.stringify 實際上會忽略 `undefined`、function 等型別
* 若需完整模擬，需處理特殊字元（如 `"`, `\n`）
* 可延伸為 deepClone（透過 parse + stringify）
* 與 deepEqual（Day 17）形成一組常見工具函式
