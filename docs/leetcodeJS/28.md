# 28. Array Wrapper

## 📝 題目（English）

Create a class `ArrayWrapper` that accepts an array of integers in its constructor.

### Features

* When two instances are added with the `+` operator, return the sum of all elements in both arrays.
* When `String()` is called, return a comma-separated string in brackets (e.g. `[1,2,3]`).

---

## 📝 題目（中文）

實作一個 `ArrayWrapper` 類別：

* 建構子接收整數陣列
* 使用 `+` 運算時回傳所有元素總和
* 使用 `String()` 時回傳 `[1,2,3]` 格式字串

---

## 💡 解題思路

* 本題核心為 **JavaScript Type Coercion（型別轉換）**
* `+` 運算會觸發 `valueOf()`
* `String()` 會觸發 `toString()`

---

## 💻 程式碼

```js
var ArrayWrapper = function(nums) {
   this.nums = nums
};

ArrayWrapper.prototype.valueOf = function() {
   let res = 0
   this.nums.forEach(n => res = res + n)
   return res
}

ArrayWrapper.prototype.toString = function() {
   return '['+ this.nums.join(',') + ']'
}

/**
 * const obj1 = new ArrayWrapper([1,2]);
 * const obj2 = new ArrayWrapper([3,4]);
 * obj1 + obj2; // 10
 * String(obj1); // "[1,2]"
 */
```

---

## 📌 重點整理

* `valueOf()`：決定數值運算時的行為
* `toString()`：決定字串轉換結果
* `+` 觸發隱式型別轉換

---

## ⚠️ 注意事項

* `+` 在 JS 中同時支援數字加法與字串串接
* 轉換順序為：valueOf → toString

---

## 🔥 延伸觀念

* Symbol.toPrimitive（更底層控制）
* 型別轉換規則（Abstract ToPrimitive）
* 與 Day 25（instanceof）同屬 JS runtime 機制

---

## 🚀 進階寫法（Symbol.toPrimitive）

```js
ArrayWrapper.prototype[Symbol.toPrimitive] = function(hint) {
  if (hint === 'number') {
    return this.nums.reduce((a, b) => a + b, 0)
  }
  return `[${this.nums.join(',')}]`
}
```

---

## 🧠 核心概念圖

```text
obj1 + obj2
   ↓
ToPrimitive
   ↓
valueOf()
   ↓
number + number
```
